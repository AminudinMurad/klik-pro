# Klik PRO v1.5.4

Klik PRO 1.5.4 is a focused presentation correction for the five-card Mouse
Mappings dashboard introduced in v1.5.3.

## Change

- Forward and Back now use the same **Shortcut** action-menu label as Middle
  and Gesture.
- Their existing **Browser →** and **Browser ←** keyboard-shortcut values remain
  visible and editable.
- Reset controls and the optional **Open App** action remain available.
- Mouse routing, configuration schema, responsive sizes, and the v1.6
  mouse-independent profile boundary are unchanged.

## Release metadata

- Version: **1.5.4**
- Build: **27**
- Minimum macOS: **13.0**
- Architectures: **Apple Silicon and Intel**

## Verification

- The full source, routing, helper, App Profile, hit-test, and deterministic
  preview gate passed.
- A dedicated shortcut-mode preview confirmed that Forward and Back show
  **Shortcut** beside their Browser arrow values.
